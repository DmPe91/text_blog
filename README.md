# Text Blog (Backend)

Бэкенд текстового блога.

## Стек

- Node.js
- Express
- MongoDB
- Firebase (деплой)

## Возможности

- CRUD для постов
- Загрузка изображений
- Валидация данных
- Авторизация

## Запуск

```bash
git clone git@github.com:DmPe91/text_blog.git
cd text_blog
npm install
```
Запуск:

```bash
npm run dev
```
